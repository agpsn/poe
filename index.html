3.29 quick reference
  • Tattoos: 10,000 shipment value per tattoo, capped at 40; 4M raw value reaches the cap. Dust does not increase tattoo count.
  • STR Tattoos: Ngakanu. DEX: Te Onui. INT: Mota Aro.
  • Runegrafts: Riben Fell = DEX, Pondium = INT, Kalguur = STR.
  • Resource values: Wheat 12, Corn 15, Pumpkin 18, Orgourd 21, Blue Zanthimum 24; ore 4/5/6/9/16; bars 16/19/24/37/64.
  • Bars: one ore becomes one bar; bars contribute about 4× shipment value and count 5× toward port quota compared with the ore.

Each worker now has an individual Level and Gold/hour field, so you can enter your actual roster instead of using an average level. Entering only a shipment target can accurately calculate the goods required, but not your personal Gold cost.
